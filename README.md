# Telegram forwarder — сайт на Render

## Деплой
1. Залей эти файлы в GitHub-репозиторий.
2. Render → New → Web Service → выбери репозиторий.
   - Build Command: `pip install -r requirements.txt`
   - Start Command: `python main.py`
3. Environment:
   - `API_ID`, `API_HASH` — с my.telegram.org
   - `ADMIN_PASSWORD` — придумай пароль для входа на сайт
   - (опционально) `SESSION` — строка сессии, см. ниже

## Использование
1. Открой URL сервиса, введи ADMIN_PASSWORD.
2. Введи номер телефона → код из Telegram (→ пароль 2FA, если есть).
3. Выбери источник и получателя, включи переключатель.

## Чтобы не вводить код после перезапуска
На бесплатном тарифе диск временный: при перезапуске сессия пропадает.
В панели нажми «Показать SESSION» и вставь строку в переменную `SESSION` на Render.
(Группы и переключатель после перезапуска выбираются заново; пересылка всегда стартует выключенной.)

## Free-тариф
Сервис засыпает через ~15 минут без запросов. Пингуй `https://<твой-сервис>.onrender.com/health`
каждые 5 минут через UptimeRobot / cron-job.org.
